# Jet Plane Simulator for Modular XR Seating Buck ✈️:
https://xlrseatingbuck-org.github.io/unreal-plane.html<br><br>
-**Description:** An Unreal Engine jet simulator meant to simulate real-world physics and procedures for flying a jet plane. Instead of a repository, I linked the web page I made that explains the systems in detail (and actually links the repository)<br>
-**Relevance:** This was a year-long team project that required me to study and implement physics, and work with both C++ and blueprint in Unreal Engine to make something functional and usable for users to test and play with. We shared resources and ideas but each worked to create our own simulations with our own focus. Mine was built to teach the terms and environment one needs to know to fly a jet plane in a realistic environment so that a user can actually feel like they've taken a flight from the Albany, Oregon airport to the Corvallis, Oregon airport. The maps are rendered with Cesium to, hopefully, increase immersion. The controls were primarily designed for the Logitech flight stick setup we had at the lab but it also works with Xinput controllers (primarily for my own testing while I coded this at home so be warned, the dual-engine setup controls a bit funky on controller).<br>

# Stained-Glass Playlist Editor 🎶: 
https://github.com/charcoalrox/Stained-Glass-Playlist-Editor/tree/main<br><br>
-**Description:** A bulk-playlist editor program I made using Pyqt5 to get around issues I have with using Windows Media Player. It can read playlists, search music, make sure playlist paths are all local instead of global (so I can use playlists on my computer and phone), create/edit playlists including changing titles and adding descriptions, and list songs I have in my music folder that aren't present in any playlists. It also doesn't break when I remove a song from a playlist and then try to remove a second song from that playlist without refreshing the page (like Windows Media Player does). As someone who like to listen to and organize thousands of songs, this has sped up my workflow significantly.F
-**Relevance:** Making a multi-page application requires pre-planning and doing at least some optimization to make sure I'm minimizing the amount of times it's required to loop over every single music and playlist file. It requires interaction with windows file systems, and shows that my priorities are great because someone (me) absolutely needed to make this application real<br>

# Fishin' Hole 🐠: 
https://github.com/charcoalrox/Fishin-Hole<br><br>
-**Description:** A fully functioning Gameboy ROM made using C and the GBDK 2020 libraries that sought to recreate the fictional game "Fishin' Hole" from Stephen King's book, End of Watch. Since it's a Stephen King-themed project I should give a **content warning** for references to suicide <br>
-**Relevance:** Solo development of a Gameboy rom requires a lot of pre-planning, user testing, and careful consideration. It's impossible to debug effectively without at least some knowledge of machine code and you have to know exactly what's going on to keep the ROM and RAM memory banks from overflowing. It's also very fun and I like showing this project off.<br>

# Client-Server message encoder 🤐: 
https://github.com/charcoalrox/Client-Server-Message-Encoder<br><br>
-**Description:** A series of C programs. The encoder and decoder are software that run on local servers and wait for users to ping them. The Users must provide a key (or key length for the encoder) and a message and the server can perform a handshake and perform their relevant task (encoding or decoding).<br>
-**Relevance:** Practice in computer networking and security. This code is meant to display an ability to interface with software and build something that can be safe against networking pitfalls like race conditions while performing it's task. Encoder keys are also a popular method of security right now making this a very relevant example of my experience.<br>
